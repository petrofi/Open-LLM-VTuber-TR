# Mikrofon ve ses çıkışı

İlk kurulumda mikrofon seçip Mikrofonu Dene'ye basın. Ses seviyesi göstergesinin hareket etmesi giriş verisinin alındığını gösterir. Testi bitirmek için sonraki adıma geçin.

Erişim reddedildiyse Windows mikrofon gizlilik iznini kullanıcı olarak kontrol edin. Uygulama bu izni otomatik değiştirmez. Başka uygulamanın aygıtı özel kullanımda tutup tutmadığını kontrol edin.

Hoparlör testi Windows varsayılan çıkışına gönderilir. Kulaklık yankıyı azaltır. Uygulamanın sesi Windows ses karıştırıcısından ayrı kısılmış olabilir.

Karakter ekranında mikrofon düğmesi konuşmayı başlatır/durdurur. Kamera ve ekran paylaşımı ayrı denetimlerle kullanılır; sihirbaz bunları açmaz.
