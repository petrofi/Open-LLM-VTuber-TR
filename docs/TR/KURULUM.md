# Windows kurulumu

1. Ana reponun Releases sayfasından sürüm adını taşıyan Setup.exe'yi indirin.
2. Aynı sayfadaki SHA256SUMS.txt ile dosya bütünlüğünü doğrulayabilirsiniz.
3. Setup.exe'yi çalıştırıp Türkçe kurulum adımlarını tamamlayın.
4. Masaüstü veya Başlat menüsünden Open-LLM-VTuber TR'yi açın.

Kurulum kullanıcı bazlıdır. Python/Node/Git kurulumu istemez; sistem PATH'i değiştirilmez. Uygulama Ayarlar → Uygulamalar üzerinden kaldırılır. Kullanıcı verileri korunur.
Installer code-sign sertifikasıyla imzalanmamıştır. Windows güvenlik ayarlarını kapatmanız istenmez.
