# İlk kurulum

Sihirbaz sekiz adımdan oluşur: Hoş geldiniz, Sistem, Mikrofon, Hoparlör, Konuşma Tanıma, Yapay Zekâ Motoru, Seslendirme ve Hazır.

Mikrofonu Dene ile gerçek giriş akışı ve ses seviyesi kontrol edilir. Sonraki adıma geçildiğinde test akışı kapanır. Test Sesi Çal varsayılan ses çıkışını kullanır.

Konuşma Tanıma ekranında yaklaşık 465 MB Faster-Whisper small modelini açıkça başlatarak indirebilirsiniz. İndirme model yüklenerek doğrulanır. Kesilen indirme yeniden başlatılabilir.

Yapay Zekâ Motoru ekranı çalışan yerel servisleri arar. Sağlayıcı yoksa Yerel Yapay Zekâ Kur veya API Sağlayıcısı Kullan seçeneklerinden biriyle ilerleyin. Modelinizin gereksinimlerini sağlayıcıda kontrol edin. Büyük modeller sessizce indirilmez.

Seslendirme ekranında Emel veya Ahmet seçilir. Türkçe Sesi Dene gerçek çevrimiçi ses üretir ve oynatır.

Sağlayıcı ayarlamadan arayüze geçmek mümkündür; yanıt almak için sonradan sağlayıcı seçilmelidir. Sihirbaz Ayarlar → Hakkında bölümünden tekrar açılır.
