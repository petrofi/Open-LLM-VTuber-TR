# Lisanslar

Backend MIT (Yi-Ting Chiu ve katkıcılar); frontend Open-LLM-VTuber License 1.0, Apache 2.0 temeli ve ilave ticari kısıtlar içerir. Dosyaların orijinal copyright bildirimleri korunmuştur. TR değişiklikleri ilgili kaynak dosyasının lisans koşulları altında dağıtılır.

Live2D Core proprietary SDK lisansı, Framework Open Software License ve örnek veri anlaşması birbirinden ayrıdır. Mao ve Shizuku örneklerinin ReadMe dosyaları korunur. Proje sahibi TR fork'unu kapsayan yayın izni bulunduğunu bildirmiştir. Bu beyan üçüncü kişilere otomatik yayın hakkı veya belge doğrulaması anlamına gelmez.

Faster-Whisper ve seçilen Systran small modelinin MIT bildirimleri korunur. Model installer'a gömülmez; kullanıcı isteğiyle sabit upstream revizyonundan indirilir. Silero VAD ve ONNX Runtime bildirimleri eklenir.

Edge TTS LGPLv3 (bir yardımcı dosyası MIT); kaynak Python dosyaları değiştirilmeden uygulama içinde bulunur. PyAV BSD-3-Clause, paketlediği FFmpeg ve codec bileşenleri ayrıca LGPL/GPL/BSD/Apache koşullarına tabidir. Dinamik kütüphaneler ayrı dosyalardır; ilgili bileşenleri değiştirme ve hata ayıklama hakları bu topluluk ürününün ek kısıtlamasına tabi tutulmaz. Backend/codec kaynakları ile Electron arayüzü ayrı process olarak çalışır.

`resources/licenses` içindeki envanterler, orijinal lisans metinleri, Electron LICENSES.chromium.html ve Release'teki THIRD-PARTY-SOURCES.zip birlikte dağıtılır. Kaynak arşivi codec sürümlerini, SHA-256 değerlerini ve build tariflerini içerir. Hiçbir lisans yalnızca paket adı üzerinden varsayılmaz.
